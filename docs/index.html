From profile to playback

Install and activate Dolby Atmos for Headphones or DTS Sound Unbound. Choose the playback device in the app, then use the corresponding tab.

Dolby Atmos

  1. Close Dolby Access and select your personalized headphone profile.
  2. Enable Atmos if the app offers it, then turn Personalized profile On.
  3. Adjust room output level and feedback in Dolby room. Your last setting follows subsequent profile imports.

DTS Headphone:X

  1. Select a binaural SOFA file, then Verify and convert.
  2. Enable DTS if needed, choose a room preset, and Apply profile.
  3. Switch between Balanced, Spacious, Original, and Off while keeping the personalized FIRs.

Application screenshots below show the previously published interface; the current UI was tested separately on an isolated desktop.

Import Equalizer APO parametric text in Headphone EQ and use Apply EQ for Atmos or DTS. DTS uses native biquads; Atmos approximates magnitude with 20 native bands. SOFA and room changes retain a selected uploaded EQ. Restore returns the saved DTS runtime profile and EQ.

Stored settings, restoration, and overrides

Settings remain on the selected device after the app closes. Audio reinitialization, device recreation, or vendor profile changes can require reapplying. Off/Restore returns the original saved profile. Dolby and DTS resets are separate and show a confirmation before clearing their saved configuration. Version and external-state warnings retain an explicit override; malformed data is rejected.

Measured renderer output

Matched Windows spatial-object captures at 30° left, 0° elevation, 1 m. The plots use mean left/right power, 1/6-octave frequency smoothing, and 2 ms impulse-response energy blocks. Matching axes; no gain normalization.

What the controls change

ControlNative configuration
Dolby room output levelScales room output taps, with signed coefficient overflow checks. Up to 150% where the profile allows it.
Dolby feedbackScales recursive feedback independently of room output level, from 0–100%.
DTS room presetCopies only the first stereo auxiliary vectors from a compatible installed preset. Personalized FIRs, second auxiliary vectors, room parameters, and panner remain intact.
DTS SOFA applyWrites the combined runtime profile, disabled headphone EQ, and transaction counter, then verifies readback.

This release includes Time-aligned SOFA interpolation, native DTS Spacious 200%/400%, and optional +6/+12 dB Dolby room gain correction. Experimental confirmations include clipping guidance. The current process cannot register a Sonic renderer in the system audio host; Sonic research remains separate from this release. Implementation and validation limits.

Balanced/Spacious extraction is mapped to DTS Sound Unbound 2026.3.31.0 and checks the installed binary and asset hashes. A version mismatch offers an override that retains the original room sends. Vendor preset binaries and decoding keys are not bundled.

Compatibility and current limits

Dolby coefficient version 1.1.0 and one 23-node DTS grid have been tested. SOFA conversion supports binaural SimpleFreeFieldHRIR and GeneralFIR, a full-sphere grid, one source distance, and integer sample delays. Other configurations may require an override or be unsupported. Native readback tests cover one Windows system.

Dolby 200% and 400% room/direct modes halve or quarter directional fields, retaining saved room taps and feedback. Optional gain correction adds +6 or +12 dB through Atmos native EQ and combines with uploaded EQ. On or Restore returns full directional gain. Custom 150% scales room taps alone.
